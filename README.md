# トルストイ『戦争と平和』全70大テーマ多読リーダー（時系列章順・厳密語順直読スラッシュ版）

レフ・トルストイの不朽の名作『戦争と平和』（全4巻＋エピローグ）から、人間洞察と戦争論が凝縮された重要70場面を完全時系列順に精選。ロシア語（一部フランス語）の品詞・語順に1対1対応したスラッシュ直読解説とネイティブ音声で学べるPWAリーダーです。

---

## 🌟 主な特徴
- 📖 **全70大テーマ完全網羅**: 1805年サロンの好戦熱からアウステルリッツ、ボロジノの死闘、モスクワ炎上、そしてエピローグの至福論まで完全時系列ソート。
- ⚡ **厳密品詞順スラッシュ直読**: 上段のロシア語単語の並び順に1対1で対応した日本語解説（note）を掲載。返り読みせず、原文の思考プロセスのまま読解可能。
- 🔊 **バイリンガル音声再生**: ロシア語（`ru`）および当時の貴族社交界フランス語（`fr`）のネイティブ音声再生に対応。
- 📱 **PWA & オフライン対応**: スマホのホーム画面に追加してアプリ化可能。地下鉄や機内などのオフライン環境でも動作します。

## 🚀 GitHub Pages での公開手順（初回のみ）

1. GitHub で新しいリポジトリを作成します：
   - Repository name: **`war-and-peace`**
   - Visibility: **Public**（公開）
   - 「Add a README file」等のチェックは入れずに「Create repository」をクリック
2. 本フォルダ内の全ファイルを GitHub にアップロード（ドラッグ＆ドロップして Commit changes）します。
3. リポジトリの **Settings → Pages** を開きます：
   - **Build and deployment** の Source: **「Deploy from a branch」**
   - Branch: **`main`** / **`/(root)`** を選択して **「Save」**
4. 1〜2分後、以下のURLで公開されます：
   🌐 **`https://marumoco.github.io/war-and-peace/`**

## 🛠️ メンテナンス手順（今後のテキスト修正・更新）

本アプリは、プログラム本体（`index.html`）と学習データ（`data.js`）が完全に分離されています。

- **テキストの誤字修正・訳文の追加・調整**:
  👉 **`data.js`** のみを編集して GitHub にアップロード（コミット）してください。
- **キャッシュ更新の手間は不要**:
  Service Worker は **ネットワーク優先（Network First）** で動作しているため、`data.js` を更新すると、ユーザーが次回ページを開いた際に自動で最新データが取得・即時反映されます。
